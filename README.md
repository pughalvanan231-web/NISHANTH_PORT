## Features Cloned
- **All Routes & Sub-pages**:
  - `/` (Home)
  - `/work` (Work Archive)
  - `/work/secnd-soul` (Project Detail: Secnd Soul)
  - `/work/lijoi` (Project Detail: Lijoi)

  - `/contact` (Contact & Inquiry)
  - `/faq` (Frequently Asked Questions)
  - `/photography` (Interactive Photography gallery)
  - `/playground` (Interactive 3D character playground & dance floor)
- **3D WebGL & Three.js Scenes**:
  - All 3D `.glb` models: Sagar character (`sagar.glb`), concept laptop (`macbook_ultra_concept.glb`), office desk & chair (`desk2.glb`, `chair.glb`, `services/chair.glb`), and skeletal animation sets (`typing.glb`, `jumping.glb`, `armStretch.glb`, `jump.glb`, `standToSit.glb`, `push.glb`, `waving.glb`, `pointing.glb`, `thumbsUp.glb`).
- **Interactive Audio & Media**:
  - Sound effects (`click.mp3`, `whoosh.mp3`) and playground audio (`gangnam.mp3`, `tennu-le.mp3`).
- **All Next.js Turbopack Assets & Styles**:
  - Space Grotesk and Space Mono fonts, Tailwind CSS & CSS modules, all project showcases, and client images.
- **Built-in Zero-Dependency Server**:
  - Features support for Next.js image optimization routes (`/_next/image?url=...`), clean route resolution, and MIME types for 3D GLB models and WOFF2 fonts.
